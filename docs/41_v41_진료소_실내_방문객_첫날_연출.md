# MIGUEL CLINIC v4.1 — 진료소 내부와 방문객 연출

## [게임 확장]
- 기존 `story` 메인 화면에 CSS만으로 구성한 진료소 내부(창문·약품 선반·진료 책상·방문객 실루엣)를 추가한다.
- 4개 시간대의 색조가 변화하며, `prefers-reduced-motion`에서는 등장 애니메이션을 제거한다.
- 날짜별 주민 인사 4종은 미겔의 간결한 대답으로 끝난다. 원작 확정 사건으로 취급하지 않는다.
- `s.v41.talked`와 `s.v41.met`는 하루 한 번의 대화 중복을 막으며 의료 예약/진료 기록과 분리된다.
- 진료·정착촌 바로가기는 기존 v36 메뉴를 사용한다.

## [원작 확정] 및 경계
- 미겔은 군의관 출신이며 현재 무료 진료소를 운영한다. 얼굴보다 목소리와 행동으로 사람을 알아본다.
- 다니엘은 군 복무 중이며 미겔과 별도로 생활한다. 게임 확장 주민 대화가 원작의 새로운 확정 사실을 만들지 않는다.

## 호환성
- `miguel_clinic_v02`, `version:2` 유지. 신규 상태는 `s.v41`에만 저장한다.
- 기존 설정 문서와 기능은 삭제하지 않는다.
