# MIGUEL CLINIC v2.7 — 통합 진료·브라우저 검증·일상 확장

## 호환성
기존 `miguel_clinic_v02` 및 최상위 `version: 2`를 유지하며, 신규 진행은 `s.v27`에만 추가한다. 기존 버전의 설정 MD와 게임 기능은 보존한다.

## [원작 확정]
델하르사, 제로 사태, 미겔의 군의관 경력과 다니엘의 현역 복무 등 기존 공식 기준을 유지한다. 제로 변이 조건과 백신, 사건 인과관계는 추가 확정하지 않는다.

## [원본 로그/해석]
미겔과 다니엘의 관계 및 체스에서의 태도는 기존 제공된 로그를 참조한다. 신규 대사는 원본 로그가 아니다.

## [게임 확장]
진료 상태 비파괴 검사, 18개 격리 회귀 검사, 백업 사전 비교, 일일 운영 장부, 주민 코미디 후일담 4편과 다니엘 일상 4편을 추가한다. 다니엘은 미겔과 상시 동거하지 않으며, 편지·통화·휴가 중 만남을 활용한다.

## 검증 한계
격리 상태 전이 회귀 검사는 브라우저 전체 UI 경로를 보증하지 않는다. 브라우저 테스트는 실행 환경에 따라 별도 확인한다. 복원 비교는 실제 복원을 수행하지 않는다.
