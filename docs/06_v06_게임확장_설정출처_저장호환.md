# MIGUEL CLINIC v0.6 — 확장 기능과 설정 출처

## 선행 참고
본 패키지의 docs/00~05 문서를 모두 읽고, 원작과 로그의 확정 범위를 확인한 뒤 제작했다.

## 기능
- [게임 확장] 선인장, 수면 청년, 할머니, 상인 대상 2단계 진료 미니게임. 실제 의료 진단 지침 아님.
- [게임 확장] 기존 `furniturePositions`, `facilities` 필드를 그대로 사용하는 시각적 6칸 진료소 배치.
- [게임 확장] 주민 관계 점수 `v06Relations` (기존 호감도나 다니엘과의 사랑에 영향 없음).
- [원작 세계관] 하얀 사막과 모래폭풍. [게임 확장] 날씨별 생활 사건과 날짜별 등장.
- [로그 모티프] 체스, 꽃, 생존과 일상, 미겔의 말투와 사람 인식 방식. [게임 확장] 작은 일상 장면 5종. 원작 로그의 후속 장면이라고 단정하지 않음.

## 보존
- 기존 첫날 프롤로그, 환자 자유 진료, 환자 대기열, 주민 일정, 날씨, 마을 지도, 진료소 시설, 가구 배치, 수첩, 다니엘 편지와 두 차례 휴가, 연속 서사를 유지한다.
- 기존 `localStorage` 키 `miguel_clinic_v02`와 저장 `version:2`를 유지한다. 새 필드는 `v06Relations`, `v06MiniWins`, `v06MiniHistory`, `v06WeatherSeen`, `v06MomentsSeen`, `v06ActiveMini`로만 추가한다.
- 날짜가 지나면 미니게임 진행 중인 세션은 초기화하지만 완료 기록은 보존한다.

## 캐릭터 및 소유권
- [확정] 미겔은 여성, 군을 떠나 자신이 선택한 방식으로 무료 진료소를 운영. 얼굴 인식 어려움은 조롱 대상이 아니다.
- [확정] 다니엘은 현역 군인으로 복무하며 미겔의 연인. 타인 오너 캐릭터이므로 내면의 미확정 동기와 새 대사는 게임 확장으로 취급한다.
- [로그] 미래 대화 → 고백 로그 → 체스·전역·재회·미래까지 한 편의 긴 원본 로그. 짧은 공개본은 편집본.
- [미확정] 제로 변이 조건·백신 완성·제로 감소의 인과관계는 게임에서 확정하지 않는다.
