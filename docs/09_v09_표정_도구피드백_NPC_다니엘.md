# v0.9 추가 개발 기록

## 원작 확정
- 미겔은 여성, 과묵하고 간결한 말투이며 타인을 목소리 등으로 구분한다.
- 다니엘은 현역 군인이자 미겔의 연인이다. 미겔을 코트리먼이라고 부른다.
- 원작의 체스·전역·재회·미래는 하나의 연속된 원본 로그다.

## 해석 (확정 아님)
- 진료소에서 일상의 안정감을 느끼는 방식은 해석 가능하지만, 미겔의 내면을 확정하지 않는다.

## 게임 확장
- 환자별 표정 단계 및 진료 도구 피드백은 게임 전용 연출이다.
- 주민의 시간대별 위치는 기존 주민 스케줄을 활용한 게임용 배치다.
- 다니엘의 먼지 정리·편지·휴식 이벤트와 대사는 모두 신규 창작이다.
- 기존 v0.8 진료, 지도, 일상, 저장 구조는 유지한다.
