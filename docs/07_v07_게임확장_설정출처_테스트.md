# MIGUEL CLINIC v0.7 — 기능과 설정 경계

## 참고한 원본
- docs/00~06의 모든 MD를 읽고 기존 v0.6 index.html을 보존한 확장 작업.
- [원작 확정] 미겔의 생존·자발적 전역·무료 진료소, 선천적 얼굴 인식 어려움, 다니엘의 현역 복무 및 연인 관계.
- [로그] 체스·꽃·미래·생존 모티프. ① 미래 대화 → ② 고백 로그 → ③ 체스부터 미래까지 하나의 긴 통합 로그.
- [해석] 평범한 일상과 사랑을 독립적으로 선택한다는 독해는 분석이지 추가 공식 사건이 아님.
- [게임 확장] 환자·주민·우편배달부·날짜·계절 주기·새 다니엘 대사·신규 이벤트·진료 미니게임 전부 신규 창작. 다니엘의 속마음은 공식 설정으로 단정하지 않음.

## 신규 기능
1. 진료 미니게임 3종: 물품 분류, 목소리 단서, 모래바람 대비. 하루 1회 각 보상.
2. 주민 5인 x 관계 2단계 = 10편. 기존 v0.6 주민 교류 수치 사용.
3. 6칸 기존 가구 배치와 시설 구매 내역을 시각화한 진료소 풍경, 테마 3종.
4. 7일 단위 계절 변화와 계절별 1회 이벤트. 실제 델하르사 기후 확정 아님.
5. 다니엘과 미겔 일상 4편. 다니엘은 군복무 중이며 일부 휴가 방문.

- 기존 `s` 저장 객체에 `v07Played`, `v07GameActive`, `v07BondEvents`, `v07SeasonSeen`, `v07DanielSeen`, `v07DecorTheme`, `v07GamesLog`만 추가.
