# MIGUEL CLINIC v2.5

## 호환성
- 이전 파일과 docs 26개 유지. localStorage `miguel_clinic_v02` 및 최상위 `version: 2` 유지.
- 신규 상태 `s.v25`에만 저장. 기존 진료 기록과 완료 기록은 삭제하지 않음.

## 안정성
- 실제 예약·접수·진료·재방문 상태 진단, 근거 있는 예약 상태만 개별 승인 후 수정.
- 진료 완료 기록 존재 시 예약을 completed로 정정, 접수 기록 존재 시 checked-in 정정. 자동 실행이나 일괄 수정 없음.
- JSON 복원 파일은 현재 데이터와 날짜, 진료 기록, 예약, 재방문 건수를 비교하며 검사 단계에서 저장을 변경하지 않음. 실제 복원은 기존 안전 슬롯 화면 사용.
- 격리된 메모리 기반 회귀 테스트 11개. 실제 브라우저 E2E 테스트와는 다름.

## 게임 확장
- 하루 1회 물자 선택, 30개 재고 상한, 부족 시 나눔 금지, 선택 전후 장부.
- 주민 코미디 4편, 다니엘 일상 4편. 각각 최초 1회만 평온 보상.
- [원작 확정] 미겔 여성, 전직 군의관, 다니엘 현역 군인 연인, 미겔은 D라고 부름, 체스는 양보하지 않음.
- [원본 로그/해석] 원본 로그 순서 및 기존 해석 유지.
- [게임 확장] 신규 주민 소동, 대사, 운영 수치, 휴가·통화 사건은 비공식 창작.
- 제로 변이 조건, 백신 완성, 대형 제로 소멸과 감소 인과관계는 확정하지 않음.
