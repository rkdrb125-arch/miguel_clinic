# MIGUEL CLINIC v1.6 — 기능과 설정 경계

## 원작 확정
- 미겔 코트리먼은 여성 전직 군의관이며 자발적으로 전역해 무료 진료소를 운영한다.
- 다니엘 레온하르트는 현역 군인인 연인이다. 미겔은 그를 D, 다니엘은 미겔을 코트리먼이라고 부른다.
- 체스에서 미겔은 일부러 져주지 않는다. 제로 변이 기전·백신·소멸 원인 등 미확정 사항은 확정하지 않는다.

## 해석 (확정 아님)
- 평범한 일상과 작은 수선, 공동체의 변화가 회복을 상징한다는 연출.

## 게임 확장 (비공식)
- NPC의 시간대별 위치에 따른 예약 접수 가능 여부, 경과 진료 이후 마을 변화, 운영 선택에 따른 관계 보조 기록.
- 우산 수집가·주전자 장인·모자 장수·라디오 수리공의 코미디 환자 사건. 현실 의료 처방 아님.
- 다니엘과 미겔의 새 편지·휴가 4편 및 선택지·등장 날짜는 비공식 창작이다.

## 저장·호환성
- 기존 키 `miguel_clinic_v02`, `version: 2` 유지. 기존 데이터 구조를 삭제하거나 변경하지 않고 `v16` 하위 필드를 추가.
- 예약·진료 결과는 기존 `v14`와 `v15` 데이터를 읽는다. 이전 버전 저장은 최초 로딩 시 기본값을 보충한다.
- 기존 대기열 접수 버튼은 위치 검증을 위해 비활성화하고 v1.6 위치·접수 화면으로 연결한다.
- 정적 JS 구문 검사와 ZIP 무결성 검사를 수행하며 실제 브라우저 회귀 검사는 별도다.
