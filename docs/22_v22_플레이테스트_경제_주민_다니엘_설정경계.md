# MIGUEL CLINIC v2.2 — 테스트 및 설정 경계

## [원작 확정]
- 미겔은 여성 전직 군의관이며, 자발적으로 전역한 후 무료 진료소를 운영합니다.
- 다니엘은 현역 군인으로 미겔과 연인 관계이며, 미겔은 그를 D라고 부르고 다니엘은 코트리먼이라고 부릅니다.
- 미겔은 체스에서 다니엘에게 일부러 져주지 않습니다.

## [해석]
- 진료소의 일상은 미겔이 선택한 삶의 연장선으로 표현합니다.

## [게임 확장]
- v2.2의 코미디 환자 후일담 4편, 다니엘 일상 4편, 운영 장부 선택지는 게임용 신규 창작입니다.
- 비파괴 점검 화면은 현재 저장 데이터의 예약/접수/진료 상태를 읽고 경고를 표시합니다. 자동으로 진료를 완료하거나 기록을 삭제하지 않습니다.
- 백업/복원은 기존 v2.1 안전 슬롯 기능을 유지합니다. 브라우저별 통합 테스트는 별도로 필요합니다.

## 저장 호환성
- localStorage 키 `miguel_clinic_v02`, 저장 객체의 `version: 2` 유지.
- 신규 진행은 `v22` 필드에만 추가하며 기존 필드를 삭제하지 않습니다.
