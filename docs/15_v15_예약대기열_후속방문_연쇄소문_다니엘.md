# MIGUEL CLINIC v1.5 — 설정 출처와 변경 기록

## [원작 확정]
- 미겔 코트리먼은 여성 전직 군의관이며 자발적으로 군을 떠나 무료 진료소를 운영합니다.
- 다니엘 레온하르트는 군 복무 중인 미겔의 연인입니다. 호칭은 다니엘→코트리먼, 미겔→D입니다.
- 미겔은 체스에서 일부러 져주지 않습니다. 제로 변이·백신·소멸의 미확정 인과는 새로 정하지 않습니다.

## [해석]
- 환자의 회복과 이웃 관계가 연결되는 것은 미겔의 일상적 선택과 돌봄을 보여 주는 게임적 해석이며 원작 확정 사건이 아닙니다.

## [게임 확장]
- v1.4 예약 환자만 대기열에 등장하며 예약 시간 이후 접수해야 진료 선택을 할 수 있습니다. 예약 없이 진료하는 기존 기능은 유지됩니다.
- 진료 선택 결과는 v15.followups에 추가 기록되며 이틀 후 2단계 후속 상담이 열립니다. 실제 의료 처방 지침이 아닙니다.
- 기존 마을 부탁에서 시작하는 다섯 단계 연쇄 소문, 친밀도/회복 단계에 따른 주민 부탁, 다니엘의 신규 편지·휴가 4편은 모두 창작 이벤트입니다.
- 다른 창작자 소유 인물의 내면과 공식 행적을 새로 확정하지 않습니다.

## 호환성 및 검증 범위
- 기존 localStorage 키 `miguel_clinic_v02`, `version:2` 그대로 유지하며 새 진행 데이터는 `s.v15`에만 추가합니다.
- v0.1~v1.4 파일, 기존 저장 필드 및 문서 보존. 기존 환자 진료 화면을 대체하지 않고 확장합니다.
- JavaScript 정적 구문 검사 및 ZIP CRC 검사. 실제 브라우저 구버전 저장 데이터 회귀 테스트는 별도로 필요합니다.
