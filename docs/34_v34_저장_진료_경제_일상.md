# MIGUEL CLINIC v3.4 — 저장·진료·장기 운영

## 호환성
기존 키 `miguel_clinic_v02` 및 최상위 `version: 2` 유지. 원본 v3.3의 파일과 MD 설정은 삭제하지 않음. 추가 데이터는 `s.v34`에 저장.

## 기능
- 저장 상태의 메모리/실제 localStorage 비교 및 구버전 JSON 읽기 전용 검사. 실제 복원은 기존 승인형 안전 복원 메뉴로 이동.
- 진료 예약·진료 날짜 및 접수·재방문 상태 점검. 기존 v2.9 예약·접수·진료·재방문 플레이 화면 유지.
- 하루 1회 운영과 물자 상한 30, 음수 자원 차단.
- 주민 후일담 4개, 다니엘 일상 4개. 모두 [게임 확장].

## 검증 범위
- Chromium에서 `set_content` 기반 진료 UI 조작 및 격리 회귀 검사.
- 실행 환경 정책으로 http://127.0.0.1, file://, 테스트 도메인 탐색이 차단됨. 따라서 진짜 origin 기반 localStorage 새로고침 복원과 과거 세이브의 실제 디스크 영속성은 미검증.
- 원작 설정: 미겔은 여성, 전직 군의관이며 진료소를 운영. 다니엘은 현역 군인으로 별거 중. 미겔은 다니엘을 D라 부르며, 다니엘은 미겔을 코트리먼이라 부름. 체스에서 고의 패배 없음.
