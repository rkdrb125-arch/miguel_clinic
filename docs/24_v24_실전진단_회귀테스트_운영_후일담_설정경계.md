# MIGUEL CLINIC v2.4

## 호환성
- 이전 게임 코드, 문서, 이미지 및 기능을 유지하는 추가 방식.
- localStorage `miguel_clinic_v02`, 최상위 `version: 2` 유지. 신규 상태는 `s.v24` 아래 저장.
- 실제 진료 상태 진단은 읽기 전용. 검사 기록만 `s.v24.reports`에 저장.

## 진단 및 테스트
- 예약/접수/진료/재방문 구조의 실제 저장 상태를 조회하고 불일치 경고를 표시.
- 8개 격리 메모리 회귀 시나리오. 이는 실제 브라우저 전 과정을 자동 클릭하는 E2E 테스트가 아님.
- 기존 v2.0~v2.3 JSON 백업/복원 화면 및 사전 검사 유지. 복원 전 백업 권장.

## 경제·이야기
- 하루 1회 물자 분류/나눔/휴식, 물자 30 상한, 물자 부족 시 나눔 차단.
- 코미디 주민 후일담 4편과 다니엘 일상 4편. 완료 보상은 각각 한 번만 지급.

## 설정 출처 구분
- [원작 확정] 미겔은 여성·전직 군의관, 다니엘은 군 복무 중인 연인. 미겔은 D, 다니엘은 코트리먼으로 부름. 체스에서 미겔은 일부러 지지 않음.
- [원본 로그/해석] 기존 연표와 대사 해석은 변경하지 않음.
- [게임 확장] 정착촌 주민, 신규 코미디, 운영 수치, 신규 편지와 휴가 장면은 비공식 창작.
- 제로 변이 조건·백신·대형 제로 소멸 인과관계는 확정하지 않음.
