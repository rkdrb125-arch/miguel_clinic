# MIGUEL CLINIC v1.7 — 구현과 출처 구분

## 선행 자료
- v1.6 ZIP의 docs MD 18개와 기존 index.html을 기준으로 한 추가 확장입니다.

## [원작 확정]
- 미겔은 여성 전직 군의관으로 자발적으로 전역해 무료 진료소를 운영합니다.
- 다니엘은 현역 군인이며 미겔의 연인입니다. 호칭은 미겔→D, 다니엘→코트리먼입니다.
- 미겔은 체스에서 일부러 져주지 않습니다. 인물의 과거 및 제로 관련 미확정 기전은 새로 확정하지 않습니다.

## [원본 로그·해석]
- 두 사람의 일상적 애정과 평온한 미래는 기존 원본 로그의 정서를 참고하되, 신규 사건을 원본 로그라고 주장하지 않습니다.

## [게임 확장]
- 게임 내 아침·낮·오후·저녁 NPC 위치와 예약 상태를 함께 보여 주는 동선판.
- 기존 v1.6 코미디 환자 네 명의 2단계 재방문 이야기.
- 기존 후속 진료 및 관계 진행을 조건으로 하는 주민 연쇄 이벤트 네 건.
- 하루 한 번의 운영 균형 선택(물자 점검, 나눔, 휴식).
- 다니엘 신규 편지·휴가 일상 네 편. 대사·날짜·선택지 모두 비공식 게임 창작.

## 저장 호환성
- `localStorage` 키 `miguel_clinic_v02`, 최상위 `version:2` 변경 없음.
- 신규 기록은 `s.v17` 아래에만 추가. 기존 필드와 기능은 유지합니다.
- 게임 시간대는 실제 시계가 아닌 기존 `s.day`, `s.phase`를 사용합니다.

## 검증 범위
- JavaScript 정적 구문 검사 및 ZIP CRC 검사를 실시합니다.
- 실제 브라우저 전 경로 플레이/기존 저장 복원은 별도 테스트가 필요합니다.
