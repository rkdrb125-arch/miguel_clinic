# MIGUEL CLINIC v2.1 — 기능·설정 경계·호환성

## [원작 확정]
- 미겔 코트리먼은 여성 전직 군의관이며 자발적으로 전역했다. 다니엘 레온하르트는 군 복무 중인 연인이다.
- 미겔은 다니엘을 ‘D’, 다니엘은 미겔을 ‘코트리먼’이라 부른다. 미겔은 체스에서 일부러 져주지 않는다.
- 제로의 변이 조건·백신·소멸 원인은 확정하지 않는다.

## [해석]
- 미겔이 스스로 선택한 일상을 진료소 운영과 이웃 관계로 표현한다. 원작 대사를 새로 확정하는 뜻은 아니다.

## [게임 확장]
- v2.1 진료 흐름 진단, 중복 알림 차단, 운영 지원, 주민 일상 3편, 다니엘 일상 4편, 안전 복구 UI는 게임용 신규 요소다.
- 다니엘 신규 대사·일정과 정착촌 사건은 비공식 창작이다. 타인 소유 캐릭터의 미확정 심리를 공식 설정으로 규정하지 않는다.

## 저장 호환성 및 검수
- `miguel_clinic_v02`, `version: 2` 유지, `v21` 추가 필드만 사용.
- JSON 복원 전에 현재 저장을 `miguel_clinic_v02_v21_pre_restore` 안전 슬롯에 보관하고, 실패 시 롤백을 시도한다.
- 정적 JS 구문 검사와 ZIP 무결성 검사는 브라우저 전체 플레이 검증을 대체하지 않는다.
