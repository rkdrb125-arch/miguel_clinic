# MIGUEL CLINIC — 개발 전 필독 (설정 인수인계)

> 다음 버전을 제작할 때 **이 파일과 01, 02 문서를 먼저 읽고** 게임의 기존 `index.html`을 확인한다. 문서를 ZIP에 넣는 것만으로 게임이나 AI가 자동으로 읽는 것은 아니다. 후속 개발자가 참조하기 위한 자료다.

## 1. 설정 우선순위
1. 사용자가 새롭게 명시적으로 확정·정정한 사실
2. 원작 세계관 확정 내용과 캐릭터 오너가 확인한 로그
3. 문서의 [해석] 표기 내용(가능한 독해일 뿐 사실 아님)
4. 게임용 신규 확장 설정(원작 사실로 역수입 금지)

## 2. 절대 유지할 캐릭터 사실
- 미겔 코트리먼은 여성. 과묵·직설·간결한 화법, 선천적 얼굴 인식의 어려움. 타인을 목소리·행동으로 구별하는 단서를 활용할 수 있다. 말투와 안면 인식의 원인을 임의로 연결하지 않는다.
- 미겔의 부모 이스마엘·존은 딸을 사랑했다. 부모를 방임/학대 부모로 각색하지 않는다.
- 미겔은 제5사관학교 제로 사태 이후 제로 전담반에서 활동했고, 스스로 군을 떠나 변방 무료 진료소를 운영한다. 그녀의 전역은 다니엘 때문만이 아니라 자기 삶과 속죄 방식에 관한 주체적 선택이다.
- 다니엘 레온하르트는 타인 소유 캐릭터. 군인으로 계속 복무하며, 미겔을 '코트리먼'이라 부른다. 그의 속마음·결정·새 과거를 오너 확정 사실로 서술하지 않는다.
- 미겔과 다니엘은 이미 연인이다. 호감도 수치가 사랑의 유무를 판정하지 않도록 한다.

## 3. RP 로그 시간순 (혼동 금지)
① 미래를 묻는 대화 → ② 별도의 고백 로그 → ③ 체스 → 전역 결심 → 실제 전역 → 다니엘에게 달려가 재회 → 꽃 → 이후 미래의 일상 → '안아줘' → '1초라도 더 사랑하고 싶다'까지 **한 개의 긴 원본 로그**. 다른 오너들에게 공개한 짧은 버전은 ③의 **편집본**이며 별도 사건/엔딩이 아니다.

## 4. 세계관 금지 추측
- 제로는 접촉·공격만으로 변이하지 않는다. 변이 원인·조건·백신 완성은 미확정. 대형 제로 소멸과 개체 감소의 인과관계도 미확정.
- 델하르사는 하얀 사막과 메인시티 방풍 돔, 극심한 빈부격차가 특징. 지도 좌표, 백사구 정착촌의 정확한 위치, 세부 인프라는 게임용 확장.
- 다른 오너의 자캐를 동의 없이 핵심 NPC로 편입하지 않는다.

## 5. 게임의 톤과 시스템
- 게임 이름: MIGUEL CLINIC. 원작 이후의 **게임 확장 이야기**.
- 배경: 가칭 '백사구 외곽 정착촌' — 가난하지만 생기 있고 기묘한 환자가 많은 변방 마을. 빈곤을 희화화하거나 주민을 일방적 구원 대상으로만 묘사하지 않는다.
- 중심: 평화로운 진료소 생활, 엉뚱한 환자 코미디, 드물게 감동과 과거의 흔적. 과거를 새로운 비극으로 덧씌우지 않는다.
- 의료 선택지는 재미를 위한 허구적 게임 장치이며 실제 진료 지침처럼 묘사하지 않는다.
- 다니엘은 상주 NPC가 아닌 현역 군인으로, 연락·휴가 때 만나는 연인.
- 체스·꽃·식물·편지·손·'1초' 모티프를 **절제해서** 일상에 섞는다. 매일 모든 상징을 반복하지 않는다.

## 6. 이벤트 설계 시 출처 표시
새 이벤트 기획서마다 `근거: [원작 확정] / [로그] / [해석] / [게임 확장]` 표기. 실제 원문 인용이 아닌 대사는 반드시 '게임용 신규 대사'로 표시. 다니엘의 내면을 확정하는 이벤트는 오너 승인 전까지 미확정 제안으로 보관.

## 7. 개발 호환성
- `index.html`을 기존 v0.3의 **실제 코드**를 기준으로 수정할 것.
- 기존 localStorage 키 `miguel_clinic_v02`, 저장 객체의 `version:2`를 함부로 변경하지 말 것. 신규 필드는 구 저장값을 병합해 마이그레이션.
- 기존 첫날 스토리, 환자, 지도, 진료 도구, 다니엘 휴가, 수첩을 보존. 배포 주소 변경 시 브라우저 저장 데이터가 자동 이전되지 않음을 알릴 것.
- 이 패키지는 **v0.3 기능 유지 + 참고 문서 동봉판**. 신규 게임 기능을 추가한 v0.4가 아니다.
