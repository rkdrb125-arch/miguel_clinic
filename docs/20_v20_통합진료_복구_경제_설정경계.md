# MIGUEL CLINIC v2.0 — 기능·출처·호환성

## [원작 확정]
- 미겔 코트리먼은 여성 전직 군의관이며 자발적으로 전역했다. 정착촌에서 무료 진료소를 운영한다.
- 다니엘 레온하르트는 군 복무 중인 연인이며, 미겔을 ‘코트리먼’이라고 부른다. 미겔은 ‘D’라고 부른다.
- 미겔은 체스에서 일부러 져주지 않는다.

## [해석]
- 평범한 진료소 운영을 스스로 선택한 삶의 연속으로 표현한다. 이는 확정 대사 인용이 아닌 연출 방향이다.

## [게임 확장]
- v2.0 진료 흐름 대시보드, 마을 변화 4종, 운영 선택 3종, 다니엘 일상 4편은 신규 창작이다.
- 저장 복구 UI와 오류 진단은 게임 도구이며 원작 사건과 무관하다.
- 세계관의 제로 변이 조건, 백신, 소멸 원인은 새로 확정하지 않는다.

## 호환성·검수
- `miguel_clinic_v02`와 `version: 2` 유지, `v20`만 추가.
- JSON 복원은 version/day/phase/flags/records 필수 구조 검증 후 사용자가 승인하면 적용한다.
- 구문 검사 및 ZIP 무결성 검사와 별도로 브라우저 통합 플레이 검증이 필요하다.
