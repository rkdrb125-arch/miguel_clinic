# MIGUEL CLINIC v0.8 — 확장 기능 및 출처 구분

## 원작 확정
- 미겔은 여성, 생존하여 스스로 군을 떠난 뒤 무료 진료소를 운영한다.
- 다니엘은 현역 군인이며 미겔의 연인이다. 미겔을 코트리먼이라 부른다.
- 미겔의 얼굴 인식 어려움은 희화화하지 않는다.
- 원본 체스→전역→재회→미래는 하나의 통합 로그이며 게임에서 재발생시키지 않는다.

## 게임 확장
- 시각 진료 퍼즐과 환자 5종의 경과 대사 및 진료 기록, 진료실/마을의 클릭형 장면, 다니엘 신규 휴가/편지 3편은 게임 전용 신규 창작.
- 신규 다니엘 대사·행동은 타인 오너가 확정한 설정이 아니다.
- 의료 퍼즐은 현실 진료 지침이 아니다.

## 저장 호환
- 기존 localStorage 키 `miguel_clinic_v02`, `version:2` 및 기존 필드를 유지한다.
- 신규 `v08*` 필드만 추가하며 v0.7 진료 기록·재고·친밀도·휴가 진행도를 보존한다.
- 같은 origin에서만 기존 저장을 자동으로 읽을 수 있다.
