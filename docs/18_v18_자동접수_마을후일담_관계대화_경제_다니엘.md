# MIGUEL CLINIC v1.8 — 구현 및 설정 출처

## 원작 확정
- 미겔 코트리먼은 여성 전직 군의관으로 자발적으로 전역한 뒤 무료 진료소를 운영한다.
- 다니엘 레온하르트는 현역 군인인 연인이며, 두 사람의 호칭은 D / 코트리먼이다.
- 미겔은 체스에서 일부러 져주지 않는다.

## 원작 로그 및 해석
- 꽃병, 체스, 편지, 평범한 일상에 관한 원작 로그의 모티프를 참고한다.
- 두 사람의 속마음이나 다니엘의 새로운 의도를 원작 확정 사실로 단정하지 않는다.

## 게임 확장
- NPC 시간대별 이동과 예약 자동 접수는 게임 내 규칙이며 실제 시간·GPS와 무관하다.
- 코미디 환자 재방문으로 열리는 마을 시설, 주민 친밀도별 신규 대사, 물자 선택지, 다니엘 신규 편지·휴가 4편은 비공식 게임 창작이다.
- 자동 접수는 예약 시간이 지났고 NPC의 현재 위치가 진료소일 때만 발생한다. 예약 미도착 시 원본 예약은 그대로 남는다.

## 호환성
- localStorage 저장 키 `miguel_clinic_v02`, 최상위 `version: 2` 보존.
- 기존 `v01`~`v17` 관련 상태를 삭제하거나 덮어쓰지 않고 `v18` 필드만 추가한다.
- JavaScript 구문 검사와 ZIP CRC 무결성 검사는 정적 검사이며 브라우저의 모든 경로를 보장하지 않는다.
