## v0.4 신규 기능
- 이웃 이야기 메뉴: 선인장 환자(3화), 수면 부족 청년(3화), 상인(2화), 할머니(2화), 체스 할아버지(2화)의 후일담. 하루에 인물당 1화 진행.
- 시설 메뉴: 약품 선반, 대기 의자, 가림막, 탁상등, 체스판 수선. 구매 후 보상과 설치 상태 영구 저장.
- 다니엘 두 번째 휴가: 8일 차부터 두 가지 선택 중 하나 진행. 현역 군인 설정 유지.
- 3일 차 꽃병, 6일 차 모래바람 등 짧은 계절/기억 텍스트.
- 무료 진료 유지: 진료 성공 시 환자 결제가 아닌 마을 운영 지원금으로 코인 획득.
- 원본 v0.1 스토리와 v0.3의 지도, 도구 진료, 첫 휴가, 수첩, 수동 저장 및 데이터 내보내기 유지.

## 저장 호환
localStorage 키는 `miguel_clinic_v02`, 저장 객체 `version:2` 그대로 유지. 이전 v0.2/v0.3 데이터는 새로운 `facilities`, `neighborStages`, `specialSeen`, `secondVacation` 기본값을 병합합니다. 같은 도메인/프로토콜에서 배포하면 기존 저장값을 읽습니다. 도메인이 다르면 브라우저 저장은 자동 이전되지 않습니다. 업데이트 전 고도화 탭에서 JSON 백업을 권장합니다.

## 원작/게임 구분
`docs/00_개발전_필독.md`, `01_델하르사_세계관_설정.md`, `02_미겔_다니엘_서사심리_아카이브.md`, `03_게임_이벤트_설계_씨앗.md`는 이전 버전 원문 그대로 동봉합니다. `04_v04_이벤트_출처와_변경기록.md`에 신규 이벤트의 근거 구분을 기록합니다. 게임 대사는 원작 직접 인용으로 표시하지 않는 한 신규 창작입니다. 다니엘은 타인 소유 캐릭터이며 신규 행동/대사는 오너 확정 설정이 아닙니다.
