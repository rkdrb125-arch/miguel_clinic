# MIGUEL CLINIC v1

독립형 HTML/CSS/JavaScript 웹게임 프로토타입입니다.

## 실행
`index.html`을 브라우저에서 열거나 GitHub 저장소 루트에 업로드하고 Vercel에 정적 사이트로 배포하세요.

## 구현
- 4종의 순환 환자 사례
- 체온계, 청진기, 혈압계, 소독솜, 밴드
- 도구 선택 후 환자 터치 또는 드래그로 사용
- 진료 단계, 진료비, 평판, 날짜
- localStorage 자동 저장 및 초기화
- 모바일 화면 대응

## 참고
실제 진단/처방을 제공하는 소프트웨어가 아닌 게임 프로토타입입니다. 아트와 게임플레이는 향후 버전에서 확장할 수 있습니다.
